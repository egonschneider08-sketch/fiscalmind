# Como contribuir

## Antes de começar

1. Consulte o cartão correspondente no planejamento e confirme os critérios de aceite.
2. Atualize a branch `develop` e crie uma branch curta usando o padrão em [docs/GITFLOW.md](docs/GITFLOW.md).
3. Faça alterações pequenas e testes pertinentes. Atualize a documentação quando o comportamento mudar.
4. Abra um pull request para `develop` usando o modelo do repositório.
5. Registre o resultado e o link do pull request no cartão do Notion.

## Padrão de commits

Use mensagens curtas que expliquem o propósito, por exemplo `docs: explicar fluxo de branches` ou `feat: importar extrato csv`. Quando aplicável, associe o cartão no corpo do commit ou PR, por exemplo `FM06`.

## Revisão

O pull request deve informar o que mudou, como foi verificado, limitações e impacto em dados. Se houver outra pessoa disponível, peça revisão. A proteção de branch e os testes automáticos serão configurados e confirmados separadamente; o texto desta página não os ativa.

## Dados e credenciais

O repositório é público. Não envie documentos fiscais, extratos, credenciais ou dados pessoais reais. Utilize exemplos sintéticos. Não inclua um segredo nem mesmo para testes.
