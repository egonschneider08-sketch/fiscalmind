# Backend

Área reservada para a API e as regras de negócio do FiscalMind.

A arquitetura proposta é um monólito modular com áreas como empresas, documentos, extratos e conciliação. Linguagem, bibliotecas, versões e estrutura definitiva serão confirmadas antes da implementação.

Ainda não há aplicação, dependências ou comandos de execução aqui. Use apenas dados sintéticos durante o desenvolvimento.
